# LittleGuard public demo

Static demonstration with public-domain CDC milestone clips and previously computed YOLO11n detections, geometric tracking, and region events. No server inference, uploads, camera access or remote notifications. Care demo records remain in this browser only.

Each clip attribution, source URL and original/playback SHA256 are in demo-data.json. Test regions are artificial evaluation regions, not real hazards. Six clips were development samples; labels were reviewed by the assistant, with no independent human relabeling. Results do not establish monitoring reliability.

Only reviewed static assets are published. Python backend, weights, household uploads, care database, credentials and machine-specific paths are excluded.
